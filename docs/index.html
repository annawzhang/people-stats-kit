1. 触达文案 AB · 双比例 z 检验

场景对齐人才评估模型：对照组标准跟进 vs 实验组按 S+/S/A 分层跟进。混合样本不参与对比的排他逻辑见 explainable-talent-scoring。

z = 3.401，双侧 p = 0.0007。相对提升 19.2%。 若要在开跑前规划样本量：从 44.0% 做到 52.0%，每组约需 612 人。

3. 招聘周期 · Kaplan–Meier

终点=入职；仍在 Offer / 观察未完记为删失。中位生存时间（一半人已入职）= 34.4 天。

4. 初筛分校准 · 预测 vs 现场面通过

分数映射到 0–1，分档对齐初筛「0–39 / 40–59 / ≥60」。gap = 真实通过率 − 平均预测分。

Brier score = 0.2271（越小越好）。高分档通过率应高于低分档，否则回头检查评分卡——与 hiring-copilot 分析页同一问题。
